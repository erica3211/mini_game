# 미니게임 모음집

React로 만든 미니게임 모음 사이트입니다.

## 게임

### ⚾ 숫자야구
- 서로 다른 숫자로 이루어진 세 자리 수(첫 자리는 1~9)를 맞히는 게임
- 숫자와 자리가 모두 맞으면 **스트라이크(S)**, 숫자만 있으면 **볼(B)**, 하나도 없으면 **아웃(OUT)**
- 기회는 5번

### 🇰🇷 한글야구
- 기본 자모(자음 14 + 모음 10) **5개로 풀리는 실제 단어**를 맞히는 게임 (예: 개미 = ㄱ ㅏ ㅣ ㅁ ㅣ)
- ㅐ·ㄲ 같은 복합 자모는 한 칸이 아니라 두 칸으로 취급 (ㅐ = ㅏ+ㅣ, ㄲ = ㄱ+ㄱ), 같은 자모 중복 가능
- 입력한 자모가 어떤 글자가 되는지 실시간 미리보기 표시 (모음-모음 → ㅐ, 자음-자음 → ㄲ 조합 인식)
- 판정은 워들 방식: 자리·자모 모두 맞으면 초록, 자모만 있으면 주황(정답에 있는 개수만큼만), 없으면 회색
- 기회는 5번, 두벌식 키보드 입력 지원 (한/영 상태 무관)

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
```

## 배포

Vercel에 배포합니다. 저장소를 Vercel에 연결하면 Vite 프로젝트로 자동 인식되며,
SPA 라우팅을 위한 rewrite 설정은 `vercel.json`에 포함되어 있습니다.

## 기술 스택

- React 19 + TypeScript + Vite
- react-router-dom (라우팅)
- 일반 CSS
