# 미니게임 모음집

React로 만든 미니게임 모음 사이트입니다.

## 게임

### ⚾ 숫자야구
- 서로 다른 숫자로 이루어진 세 자리 수(첫 자리는 1~9)를 맞히는 게임
- 숫자와 자리가 모두 맞으면 **스트라이크(S)**, 숫자만 있으면 **볼(B)**, 하나도 없으면 **아웃(OUT)**
- 기회는 5번

### 🇰🇷 한글야구
- 기본 자모(자음 14 + 모음 10) **5개로 풀리는 실제 단어**를 맞히는 게임 (예: 개미 = ㄱ ㅏ ㅣ ㅁ ㅣ)
- ㅐ·ㄲ 같은 복합 자모는 한 칸이 아니라 두 칸으로 취급 (ㅐ = ㅏ+ㅣ, ㄲ = ㄱ+ㄱ), 같은 자모 중복 가능
- 입력한 자모가 어떤 글자가 되는지 실시간 미리보기 표시 (모음-모음 → ㅐ, 자음-자음 → ㄲ 조합 인식)
- 판정은 워들 방식: 자리·자모 모두 맞으면 초록, 자모만 있으면 주황(정답에 있는 개수만큼만), 없으면 회색
- 기회는 5번, 두벌식 키보드 입력 지원 (한/영 상태 무관)

### 🎉 파티게임
방 코드로 여러 명이 모여 라운드를 이어가며 노는 실시간 멀티플레이 모음입니다 (`/party`). 방장이 설정한 순서(또는 무작위 순서)로 아래 미니게임들이 한 라운드씩 진행되고, 라운드마다 등수에 따라 점수를 받아 최종 라운드가 끝나면 누적 점수로 순위를 가립니다.

#### ⏱️ 인간 정밀시계: 10초를 맞혀라
- 마음속으로 초를 세다가 정확히 10.00초라고 생각하는 순간 버튼을 눌러 멈추는 직감 게임

#### 🐭 소곤소곤 쥐 세 끼
- 집 안 방들을 스와이프로 넘겨가며 숨은 쥐를 찾아 터치 — 잡으면 곧바로 다른 방에 새 쥐가 나타나 계속 이어짐
- 제한시간 30초 동안 가장 많이 잡은 사람이 승리

#### 🎈 간 떨리는 풍선 담력 테스트
- 풍선을 눌러 부풀릴수록 터질 위험이 커지는 눈치싸움 — 터지기 전에 "그만두기"로 크기를 확정
- 최대한 크게, 안전하게 멈춘 사람이 승리 (터지면 이번 라운드 0점)

#### 🔢 숫자 미로 1 to 25
- 화면에 흩어진 숫자 1부터 25까지 순서대로 최대한 빠르게 터치

#### 🎨 절대색감? 절대착각!
- 배경(색상 지도)을 드래그해서 화면 중앙 핀이 가리키는 색을 제시된 정답 색에 최대한 맞추는 게임
- 3라운드 합산 일치율로 승부

#### 🔤 뇌회전 풀가동! 초성 타자왕
- 초성만 보고 정답을 입력 — 10초 후 카테고리, 20초 후 뜻이 순서대로 공개됨
- 제한시간 60초 안에 빨리 맞힐수록 높은 점수

#### 💸 솔드아웃: 코인 영끌 경매
- 미스터리 물품 4개에 각자만 보이는 힌트 카드를 참고해 예산을 비공개로 베팅
- 물품별 최고가 낙찰(동점이면 유찰), 남은 돈 + 낙찰 물품 가치 합산이 가장 높은 사람이 승리

#### 📸 몸으로 뛰어라! 찰칵 스캐빈저
- 제시어(사물/색상)에 맞는 물건을 30초 안에 찾아 카메라로 촬영
- 온디바이스 AI(TensorFlow.js)로 일치율을 계산해 정확도 + 속도 점수 합산, 3라운드 진행

#### 🎤 샤우팅 질주: 목소리로 가즈아!
- 마이크에 대고 소리를 질러서 목소리 크기(dB)로 내 차를 가속시키는 레이싱
- 20초 안에 결승선까지 먼저 도착하면 승리

#### 🖌️ 방해 금지! 픽셀 영토 전쟁
- 공유 캔버스를 드래그해 내 색으로 칸을 칠하는 땅따먹기 — 다른 사람이 칠한 칸도 지나가면 덮어씀
- 제한시간 20초 후 내 색 칸이 가장 많은 사람이 승리

#### 🖍️ 이심전심 그림 맞히기
- 한 명씩 돌아가며 출제자가 되어 제시어를 그림으로만 표현(글자·숫자 금지), 나머지는 채팅으로 정답을 맞힘
- 빨리 맞힐수록 높은 점수, 전원이 한 번씩 출제자를 마치면 합산 점수로 순위 결정

#### ⌨️ 타닷타닷 텍스트 레이스
- 위에 뜨는 문장을 정확히 입력 — 맞으면 초록, 오타면 빨갛게 흔들리고 고쳐야 앞으로 나아감
- 타자 속도가 빠를수록 내 차도 빨리 굴러가고, 90초 안에 문장 5개를 다 치면 완주
- 완주 후에는 아직 달리는 다른 사람의 트랙을 눌러 실시간으로 구경하는 관전 모드 제공

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
```

## 배포

Vercel에 배포합니다. 저장소를 Vercel에 연결하면 Vite 프로젝트로 자동 인식되며,
SPA 라우팅을 위한 rewrite 설정은 `vercel.json`에 포함되어 있습니다.

## 기술 스택

- React 19 + TypeScript + Vite
- react-router-dom (라우팅)
- 일반 CSS
